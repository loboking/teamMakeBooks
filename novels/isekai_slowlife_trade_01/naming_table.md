# 호칭표 — 이계 무역가 차하린

> **결정론적 호칭 검수기의 ground truth.** 본문 속 모든 인물 간 호칭은 여기 정의된 것만 사용.

## 차하린 ↔ 마린 (이계 마을 약초 상인)

```
[차하린 → 마린]: "마린 누나"      (사석/친밀, 기본)
[차하린 → 마린]: "마린 씨"        (첫 만남, 1~2회만)
[마린 → 차하린]: "하린이"          (사석/친밀, 기본)
[마린 → 차하린]: "꼬마 무역가"    (장난스러움)
```

## 차하린 ↔ 한도영 (학교 동급생)

```
[차하린 → 한도영]: "한도영"        (학교/공식, 거리감)
[한도영 → 차하린]: "차하린"        (1막, 거리감)
[한도영 → 차하린]: "하린아"        (2~3막, 친해진 후)
```

## 차하린 ↔ 도원 영감 (이계 마을 어른)

```
[차하린 → 도원 영감]: "도원 영감님"
[도원 영감 → 차하린]: "꼬마"      (장난)
[도원 영감 → 차하린]: "하린이"    (진지)
```

## 차하린 ↔ 좌선장 (이계 거대 길드 수장, 적대자)

```
[차하린 → 좌선장]: "좌선장"        (호명)
[차하린 → 좌선장]: "당신"          (격투/대치)
[좌선장 → 차하린]: "꼬마 무역가"  (조롱)
[좌선장 → 차하린]: "차하린"        (정면 대치)
```

## 서술 규칙 (회차 작가용)

- 서술에서 "차하린"(풀네임) 회차당 **5회 이내**
- 나머지 90%는 "**하린**" 또는 대명사 "**그녀**" 또는 **주어 생략**
- 한 문단에 같은 풀네임 2회 이상 등장 금지
- "차하린은 ~했다."가 5문장 연속 시작 금지
- 마린 등 조연도 풀네임 회차당 5회 이내. 첫 등장 후엔 짧은 이름.
