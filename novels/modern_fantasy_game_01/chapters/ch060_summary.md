**[요약 및 다음 회차 참고 사항]**

**등장 인물:** 강이준 (Lv6/C급 공식, B급 상위 마나 노출, 은폐 헌터 분류 확정, 길드원들에게 진실 일부 공개), 김태석 (A급, 병원 입원 — 갈비뼈 2개 골절 + 내출혈, 이준 B급 사실 목격), 세린 (B급, 병원 입원 — 왼팔 골절 + 마나 회로 30% 손상, 이준 협회 방해 시도), 윤새벽 (v1.3, 공식 협력 체결 — "필요한 순간에만 함께 일하자", 박세진과도 같은 제안 받았음), 서동현 (백화 前, USB 데이터 협회 제출용 변환 — 박세진 이름과 자신 이름 노출 위험 감수), 박동현 (C급, 병원 수술 후), 김하늘 (D급), 이명호 (D급).

**일어난 사건:** ch059 전투 직후. 구급차가 김태석 이송. 이준이 길드원들(박동현, 김하늘, 이명호)에게 진실 일부 공개: "C급은 공식 등급. 실제로는 B급 이상 마나를 제어할 수 있어요." 박동현: "등급이 뭐가 중요해. 형이 우리를 지켜줬잖아." 이준 병원에서 김태석 면회. 김태석: "네가 있어서 철혈이 버틸 수 있었어. 고맙다."

이준이 윤새벽에게 상황 보고. 윤새벽: 은폐 헌터 분류 = 한도혁이 기다린 순간. 대응 = USB 협회 제출 (상호확증파괴). 서동현 연락: USB 데이터 표준 포맷 변환 가능, 단 출처 노출 (박세진 + 서동현 이름). 서동현: "상호확증파괴. 둘 다 무사히 끝날 수는 없지만 둘 다 무너뜨릴 수는 있어요."

밤 10시 홍대에서 윤새벽 2차 만남. 이준이 공식 협력 제안. 윤새벽: "2년 전 박세진한테도 같은 제안을 받았어." 윤새벽 수락: "필요한 순간에만. 나는 드러나지 않아. 네가 부르면 올게." 윤새벽 경고: "한도혁은 보유자를 버리지 않아. 죽여서 시스템을 빼앗아."

시스템: [퀘스트 완료 — 철혈의 보호] [새 퀘스트 — 은폐의 대가 / 협회 조사 버티기 + 한도혁 압력 차단]. 2막 전반 종료, 2막 후반 시작.

**새로운 정보:**
- 윤새벽-박세진 관계: 2년 전 박세진에게 같은 협력 제안 받음. 박세진 사후 한도혁에게 도망.
- 상호확증파괴 전략: 이준 은폐 헌터 vs 정재훈 인위적 등급 조작. 둘 다 조사.
- 서동현 위험: USB 변환 시 박세진 이름 + 자신 이름 노출. 백화에서 이미 해고될 가능성.
- 한도혁 체스 분석 (이준): 1수 길드원 위협 → 2수 정재훈 공격 → 3수 마나 노출 유도 → 4수 협회 체포.
- 세린 캐릭터: 이준의 본명 사용 ("강이준"), 강한 의지 표현.

**이준 상태:**
1. **레벨/능력**: Lv6 (C급 공식, 은폐 해제 → B급 상위 노출). 진명 감지 1.2km, 마나 은폐, 마나 해독(진화), 진명 서명.
2. **동맹**: 윤새벽 = 공식 협력 체결. 서동현 = USB 데이터 변환 협조.
3. **보유 증거**: USB (마나 장치 설계도, 박세진 연구 노트, 한도혁/정재훈 마나 패턴). 내일 협회 제출 예정.
4. **가족 상태**: 어머니 협회 시설. 이서 학교.
5. **퀘스트**: "은폐의 대가" — 협회 조사 버티기 + 한도혁 압력 차단.
