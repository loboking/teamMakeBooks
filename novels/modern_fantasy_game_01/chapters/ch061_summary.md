**[요약 및 다음 회차 참고 사항]**

**등장 인물:** 강이준 (Lv6/C급 공식, B급 상위 마나 노출, 협회 본부 출석), 박경호 (심사과장, 50대, 공정한 베테랑), 유수진 (심사과 차장, 40대, 데이터 검증 담당), 최동혁 (조사관, 30대), 이정호 (이사회 이사, 한도혁 대리인, B급, 한도혁 마나 흔적), 윤새벽 (전화/메시지, 전략 코칭), 서동현 (USB 변환 담당, 비대면).

**일어난 사건:** 오전 9시 30분 헌터협회 본부. 이준이 마나 은폐를 해제하고 B급 상위 마나를 노출하며 입장. 심사과 301호에서 박경호·유수진·최동혁의 조사 시작. 뒤쪽 창가에 한도혁 대리인 이정호가 배석. 이준이 "은폐가 아닌 측정 시스템 한계" 윤새벽 전략 실행 — F급 등록 사실을 근거로 제시. 이정호가 검증 가능성을 추궁하자 이준이 태블릿(서동현 변환 USB 데이터) 제출 — 정재훈 우측 전완부 인위적 증폭 장치 이식, 마나 의존도 68%, 자연 마나 B급 하위 폭로. 유수진이 협회 표준 포맷 확인. 15분 정회 후 박경호 결정: 1) 이준 은폐 헌터 조사 2주 개시(활동 제한 없음, 정기 마나 측정), 2) 데이터 검증 후 정재훈 등급 조작 조사 병행, 3) 데이터 출처 보호. 복도에서 이정호가 "오늘은 시작일 뿐"이라 경고. 윤새벽 전화 — "한도혁 다음 수 준비해."

**새로운 정보:**
- 이정호: 이사회 이사, 한도혁 대리인, B급, 마나 패턴에 한도혁 흔적.
- 협회 규정 제47조: 등급 은폐 시 최대 1년 활동 정지 + 벌금.
- 박경호: 20년 베테랑, 한도혁 파벌 아님 — 양측 병행 조사 결정.
- 협회 로비 감지 시스템 기록이 이준의 방어 근거 ("은폐가 아닌 측정 한계").

**이준 상태:**
1. **레벨/능력**: Lv6 (Lv7 진행도 60% → 70%), C급 공식, B급 상위 노출. 진명 감지 1.2km, 마나 은폐, 마나 해독, 진명 서명.
2. **공개된 비밀**: 협회에 B급 이상 마나 공식 노출. 진명 시스템 자체는 비공개 유지.
3. **가족 상태**: 어머니 협회 시설, 이서 학교 — 변동 없음.
4. **퀘스트**: "은폐의 대가" 단계 1 완료 (협회 조사 개시 + 정재훈 조사 병행 확정), 다음 단계는 정재훈 조사 실행 대기.

**미해결 떡밥:**
1. **정재훈 강제 검사**: 우측 전완부 장치 발견 위해 협회 정밀 검사 필요, 한도혁이 이정호 통해 막을 가능성. (ch062)
2. **서동현 신변**: USB 출처 노출로 백화 보복 위험. (ch062)
3. **이정호의 다음 수**: "이건 시작일 뿐" 경고. (ch062-)
4. **Lv7 진화**: 진행도 70%, 던전/특별 이벤트 경험치 필요. (ch063-064)
5. **김태석/세린 부상**: 병원 치료 중. (ch062-063)
