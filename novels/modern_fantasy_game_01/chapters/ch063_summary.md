**[요약 및 다음 회차 참고 사항]**

**등장 인물:** 강이준, 김태석 (퇴원, 갈비뼈 유합 단계, 전투 불가), 세린 (퇴원, 왼팔 깁스 해제, 마나 70% 제한, 2주간 전투 불가), 박동현·김하늘·이명호 (길드원 5명 체제), 윤새벽 (전화/메시지), 박경호 (이사회 출석 추천 협조 예정).

**일어난 사건:** ch062 다음 날 (이사회 표결 1일 전). 아침 철혈 길드 1층 회의실 소집. 김태석이 길드 현황 공유 — 3개월 전 12명 → 현재 5명, 백화 압박으로 8명 이탈. 철혈 재건 3원칙 발표(길드원 모집 / C급 던전 의뢰 수주 / 매수 즉시 보고). 세린이 복도에서 서동현 안부 묻고 한도혁 타도 의지 표명. 오후 이준 단독 C급 던전 진입 — 마나 해독으로 효율 사냥, 보스 처치, Lv7 진행도 75% → 80%. 오후 6시 박동현이 길드 점심 외출 중 백화 산하 B급 길드 헌터에게 회유 받음(월급 3배 + 던전 우선 + "이준 곧 협회에 잡힌다" 소문 유포). 박동현 거절. 저녁 8시 윤새벽 통화 — 정재훈 조사 지연(이정호가 심사과 압력), 데이터 검증 늦음. 한도혁이 협회 "정식 이의 제기" 추가 접수 — 미등록 S급 후보로 지목, S급 연구 시설 등급 재측정 요구. 이의 제기는 이사회 표결로만 기각 가능. 밤 11시 옥상에서 진명 감지 — 백화 본사 한도혁 S급 + A급 2개(정재훈 외) 전투 태세. 윤새벽 전략 — 9명 중 한도혁 파벌 4 / 중립파 3 / 반대파 2, 중립파 2명 확보 시 4대5 기각. 박경호에게 이사회 직접 출석 요청 결정, ch059 전투 데이터 제출 카드 준비. Lv7 진화 내용 사전 공개 — 마나 해독 고급화 + 진명 서명 범위 확대 + 새 능력 "마나 차단" (상세 불명).

**새로운 정보:**
- 철혈 5인 체제 확정: 김태석/세린/이준/박동현/김하늘/이명호 (사실상 6명, 김태석 본문 표현 혼선).
- 이사회 구성 9명: 한도혁 파벌 4(이정호 외) / 중립파 3 / 반대파 2.
- 협회 규정 제52조: S급 후보 등급 재측정 — 정식 이의 제기 시 이사회 결의로 강제.
- Lv7 예정 능력: "마나 차단" — 대상 마나 일시 차단 (상세 미공개).
- 헌터 커뮤니티에서 "강이준 = C급으로 등록된 B급 헌터" 소문 확산, 사기꾼/사연 있는 자 양분.

**이준 상태:**
1. **레벨/능력**: Lv6 (진행도 80%), C급 공식, B급 상위 노출. 진명 감지 1.2km, 마나 해독.
2. **동맹**: 윤새벽 (협력), 박경호 (이사회 출석 추천 협조 예정).
3. **가족 상태**: 어머니 협회 시설, 이서 학교 — 변동 없음.
4. **퀘스트**: "은폐의 대가" 단계 2 (이사회 표결 대기) / 표결 결과에 따라 보상 변동.

**미해결 떡밥:**
1. **이사회 표결 (내일)**: S급 연구 시설 이관 통과 시 이준 격리, 기각 시 한도혁 다른 수. (ch064)
2. **이준 직접 출석 발언**: 박경호 추천 필요, ch059 전투 데이터로 정재훈 부인 무력화. (ch064)
3. **중립파 한 명 추가 설득**: 유수진 보고에 의존하는 이사 외 1명 미확보. (ch064)
4. **Lv7 진화 (마나 차단 등)**: 진행도 80%, 표결 후 던전 진입 예정. (ch064)
5. **백화 매수 공세**: 박동현 외 다른 길드원 접근 가능성. (ch064-)
6. **서동현 신변**: 5일째 연락 두절. (ch064-)
