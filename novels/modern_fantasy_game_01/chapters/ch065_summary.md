**등장 인물:** 강이준 (Lv7), 윤새벽 (전화/메시지), 김태석 (전화), 이지수 (B급, 28살, 백화 산하 '호랑이' 길드 출신, 좌측 흉부 장치 의존도 45% — 철혈 합류), 정재훈 (한도혁 가택 연금, 등장 없음), 한도혁 (전화 직접 등장, 최후통첩), 이정호 (이사회 긴급 회의 발의), 박경호·유수진 (협회 측 동행), 세린 (이서 학교 경호 확인 메시지), 한도혁의 새 부하 (이중 회로 A급, 1.5km 거리 감시).

**일어난 사건:** ch064 다음 날 아침. 정재훈 A급 정지 뉴스 폭발 — 헌터 커뮤니티 1만 댓글 폭주. 윤새벽 — 백화 균열 보고, 한도혁이 정재훈에게 "네가 선택한 거다" 후 가택 연금. 오전 10시 김태석 전화 — 이지수가 철혈 합류 희망. 오후 2시 이지수 면담, 마나 해독 고급화로 좌측 흉부 장치 식별(자연 마나 C급 상위), 합류 환영. 오후 4시 협회 사무총장실 전화 — 한도혁이 이사회 긴급 소집 요청, "이준 즉시 구금" 안건. 진명 감지로 800m 거리 A급 + 한도혁 마나 패턴 유사 이중 회로 흔적 포착(한도혁의 새 부하). 다음 날 오전 10시 이사회 긴급 회의. 이정호가 마나 해독 = 특수 능력형 S급 후보 + 정재훈 장치 무력화 = 협회 인정 마나 장치 해킹 주장. 이준이 1) 마나 해독은 타고난 능력 2) 정재훈 장치는 불법 장치 3) 한도혁의 진짜 이유는 강철민·박세진을 죽인 마나 장치 폭주 설계도 보유 폭로로 반박. 표결 한도혁 파벌 4 찬성 / 반대파 2 + 중립파 3 반대 = 4대5 구금 기각. 대신 2주 후 협회 중립 조사관 정식 등급 재측정 결정. 오후 협회 나오는 길에 진명 감지 — 500m 거리 한도혁 S급 반응 접근, 200m·150m에서 멈추고 모르는 번호로 직접 전화. 한도혁: "Lv7 도달했군. 3일 안에 항복해. 가족·길드원·서동현 살려준다." 이준 거부. 가족·박세진 죽음 언급. 세린에게 이서 학교 경호 확인 → 경호원 2명 정상이나 학교 근처 수상 차량 1대 신고. 김태석이 전투 불가에도 직접 경호 확인 출동. 밤 옥상 진명 감지 — 한도혁 백화 본사, A급 3개(이중 회로 1 + 백화 2). 마나 해독 원거리(3km, 해상도 낮음)로 한도혁 분석 — 마나 코어에서 제3의 마나 흐름 감지 = 한도혁이 시스템 설계자와 직접 연결된 증거. 새 퀘스트 "한도혁의 최후통첩" 발생.

**새로운 정보:**
- 백화 균열: 정재훈 A급 정지 후 산하 헌터들 동요, 일부 이탈 시작. 이지수가 첫 사례.
- 정재훈 장치 제거 시 마나 회로 붕괴 → 평생 C급 이하 추락. 한도혁이 가택 연금.
- 한도혁의 새 부하 (이중 회로): 한도혁 자신의 마나를 일부 이식, 정재훈보다 안정/강력. 시스템 설계자 직접 연결.
- 한도혁 마나 코어의 "제3의 마나 흐름": 한도혁이 보유자가 아니라는 증거 + 시스템 설계자와의 직접 연결 증거.
- 협회 결정: 2주 후 중립 조사관 주도 정식 등급 재측정.
- 이서 학교 근처 수상 차량 1대 — 한도혁 측 추정.
