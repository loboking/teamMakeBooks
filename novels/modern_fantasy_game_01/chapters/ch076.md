# 76화. 두 가지 S급

골목. 이준과 김태석 vs 새 A급 부하.

김태석이 앞에 섰다. A급 방패수. 부하의 공격을 정면으로 받았다. 마나 충격파를 마나 실드로 흡수.

김태석: "이준아! 옆에서!"

이준이 측면으로 이동했다. 진명 감지로 부하의 이중 회로 동기화 시차 0.3초를 다시 확인. 김태석이 정면 압박. 부하의 주의가 김태석에게 향했다.

이준이 시차를 노려 후방 공격. 근력 32. 타격 성공. 부하의 등에 균열.

부하가 분노했다. 이중 회로 과부하 가동. 마나 폭발. 김태석이 실드로 방어. 하지만 과부하의 위력은 A급 상위 한계.

이준이 마나 차단을 가동했다. 200m. 8초. 부하의 과부하 마나 차단. 폭발 중단.

8초간 이준과 김태석의 합동 공격. 김태석의 A급 마나 강타 + 이준의 차단 해제 직후 근력 폭발.

부하가 크게 타격을 받았다. 이식 회로에 균열이 생겼다.

부하가 비틀거렸다. "이... 이게 Lv8의 전투력?"

부하가 마나를 수습하고 퇴각을 준비했다.

"강이준. 이건 시작이야. 37층에서 보겠다. 회장님이 기다리고 계시니까."

부하가 A급의 속도로 도주했다. 이준이 진명 감지로 추적. 3km 밖으로 이탈.

[전투 결과: 부하 퇴각 / 부하 피해: 이식 회로 균열 / 이준 피해: 우측 팔 골절 악화 / 김태석 피해: 흉터 재발 / 마나 차단 실전 기록: A급 상위 차단 8초 성공]

***

전투 후. 이준과 김태석이 길드로 이동했다.

김태석: "이준아. 너 정말 강해졌어. 마나 차단으로 A급 상위를 8초간 멈추게 하다니. 그건 거의 S급 기술이야."

이준: "아직 멀었어요. 8초 동안 끝내지 못했으면 마나 차단 쿨타임 45초 동안 무방비 상태예요."

김태석: "그래도 충분해. 그 부하가 퇴각했잖아. 이식 회로에 균열까지. 한도혁의 수리가 필요할 거야."

길드 사무실. 이준이 마나 해독으로 부하의 이중 회로를 분석했다.

[새 A급 부하 분석 / 마나 총량: A급 상위 / 마나 구조: 이중 회로 (자연 + 이식) / 이식 회로: 시스템 설계자 직접 이식 추정 / 약점: 동기화 시차 0.3초 / 현재 상태: 이식 회로 균열 (수리 필요) / 위협도: 최상]

[Lv9 진행도: 15% → 17%]

***

밤. 이준이 길드 옥상에서 진명 감지 5km 가동.

서울 전체의 마나 반응이 스캔되었다. 4km 거리. S급 반응. 한도혁과 다른 패턴. 어젯밤과 같은 위치.

이준이 마나 해독 고급화로 S급 보유자를 분석했다. 5km 거리에서 해상도는 여전히 낮지만 Lv8 진화 후 분석 능력이 향상되었다.

[S급 보유자 원격 분석 / 거리: 4km / 마나 총량: S급 하위 / 마나 밀도: 3.1 (이준의 2.8보다 높음) / 마나 패턴: 진명 시스템 공통 주파수 92% 일치 / 특이점: 마나에 미세한 불안정 흔적 / 위치: 강남구 특정 건물 / 추정: 보유자가 건물 내 대기 중]

92% 일치. 윤새벽의 v1.3은 80%대. 이 보유자는 92%. 박세진의 v1.7은... 알 수 없었다. 사망 후 펜던트 비활성.

진명 시스템 버전이 높을수록 일치율이 높다. 92%이면 v1.8~v2.0 사이.

이준이 윤새벽에게 메시지를 보냈다.

"S급 보유자 위치 파악했어요. 강남구. 마나 밀도 3.1. 주파수 92% 일치. 박세진 씨의 v1.7과 유사한 수치예요."

윤새벽의 답장이 2분 뒤에 왔다.

"...92%. 높아. 그리고 마나 밀도 3.1. 그건 생존한 보유자가 맞아. 하지만 누군지는 내가 직접 확인해야 해. 강남구 건물이지? 내일 내가 가볼게."

이준이 밤하늘을 올려다보았다. 미확인 S급 보유자. 아군인지 적인지 모르는 존재. 대한민국에.

[Lv9 진행도: 17% → 18%]
