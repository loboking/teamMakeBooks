# 86화. 관리자
진명 시스템에 접속했다. 관리자 권한. 시스템 전체가 시야에 펼쳐졌다.

새로운 메시지들이 쏟아졌다.

[관리자 권한 레벨 1]
[시스템 전체 현황 열람 가능]
[보유자 시스템 제어 가능]
[마나 장치 원격 비활성화 가능]
[등급 측정 시스템 접근 가능]

첫 번째로 확인한 것 — 한도혁의 장치.

시스템 내에 한도혁의 이중 회로 정보가 기록되어 있었다. 시스템 설계자가 7년 전 설치한 장치. 한도혁의 마나 코어에 제3의 마나 흐름을 만든 원천.

[한도혁 이중 회로 — 시스템 설계자 설치]
[설치일: 7년 전]
[설계자 ID: ???]

비활성화를 시도했다.

[비활성화 권한 부족]
[레벨 2 필요]

"레벨 2가 필요해요."

***

도서윤이 37층에서 빠져나왔다. 심연 외부에서 윤새벽이 기다리고 있었다. 김태석과 세린도 합류했다.

도서윤이 숨을 몰아쉬며 말했다.

도서윤: "한도혁이 나왔어. 37층에서."
"어디로?"
도서윤: "백화 본부. 한도혁이 직접 갔어."

진명 감지 5km를 가동. 한도혁의 A급 하위 마나가 백화 본사에서 감지됐다.

시스템에 다시 접속했다. 레벨 2를 얻으려면 — 무엇이 필요한지 확인.

[레벨 2 해금 조건]
[보유자 v2.0의 Lv9 진화 완료]
[진화 완료: 진행도 100%]

Lv9 진화가 아직 완료되지 않았다. 진행도가 남아 있었다.

마나를 집중했다. Lv9의 마나가 몸 전체를 순환하고 있었다. 진화의 마지막 단계.

[진화 완료]
[레벨 2 해금]
[새 능력: 관리자 접속 — 시스템 구조물 원격 접속]
[마나 차단: 200m/8초 → 500m/12초]
[진명 감지: 5km → 10km]
[마나 해독: 시스템 장치 원격 분석 가능]

즉시 한도혁 장치 비활성화를 시도했다.

[한도혁 이중 회로 — 비활성화 완료]

백화 본사에서 한도혁이 느꼈다. 몸 안에서 제3의 마나 흐름이 사라졌다. 7년간 느껴온 시스템 설계자의 마나가 끊어졌다.

S급의 마나가 A급 하위로 추락. 아니 — 장치에 의존했던 마나가 사라진 것이다.

한도혁: "...뭐야?"

한도혁이 자신의 마나를 확인했다. 이중 회로가 비활성화됐다. 마나 코어의 제3 흐름이 사라졌다. 남은 건 자연 마나. A급 하위.

시스템 심층 접근을 시도했다. 관리자 권한으로 시스템 내부 구조를 확인.

[시스템 설계자 기록 발견]
[설계자 ID: ???]
[최근 접속: 7년 전]
[접속 위치: ???]
[설계자 상태: 활성]

"7년 전... 한도혁이 시스템 설계자와 접촉한 시점이야."

윤새벽: "설계자가 누군지 알 수 있어?"

더 깊이 파고들려 했다.

[접근 권한 부족]
[레벨 3 필요]
[레벨 3 해금 조건: ???]

조건이 표시되지 않았다. 아직 열리지 않은 정보.

박경호에게 연락했다.

"박경호 과장님. 이준입니다. 관리자 권한으로 한도혁의 마나 장치를 비활성화했습니다. 시스템 내 증거를 확보했습니다."

박경호: "...관리자 권한?"

"설명이 길어요. 나중에. 지금 필요한 건 — 한도혁을 체포하는 겁니다. 장치 비활성화로 전투력이 A급 하위로 추락했습니다."

박경호: "기다려. 이사회를 소집하겠다."

핸드폰을 내려놓았다.

윤새벽: "한도혁은 장치를 잃었어. 하지만 물리적으로 여전히 위험해."

"알아요. 끝내야 합니다."
