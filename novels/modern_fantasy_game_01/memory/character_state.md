## 강이준 (주인공)
- **최종 등급**: 무등급 (Beyond Rank). 진명 시스템 관리자.
- **진명 시스템 버전**: v2.0.
- **관리자 권한**: 레벨 3 (심층 접근). 게이트 개폐 권한 보유.
- **위치**: 철혈 길드 (서울). 일상 복귀.
- **가족**: 어머니 요양 시설 (의식 회복, 장치 비활성화로 호전). 이서 학교 정상 등교.
- **주요 동맹**: 세린, 윤새벽(v1.3), 도서윤(v1.9), 최서연(v1.1), 김태석.
- **달성**: 감독자 분리, 시스템 재부팅, 마나 장치 전국 비활성화, 보유자 연합 결성.

- **역할**: 이준의 동반자. 철혈 길드 핵심.
