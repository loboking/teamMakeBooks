# 캐릭터 상태 — 무등급 헌터

> 각 인물의 현재 시점 스냅샷. 변경 시마다 갱신.

## 강이준
- **표면 등급**: F (변동 없음)
- **실제 등급**: F (1화 이전, 진명 시스템 미각성 상태)
- **레벨**: 1
- **보유 스킬**: (없음 — 1화에서 각성 예정)
- **위치**: 길드 사무실 / 던전 입구
- **건강 상태**: 정상
- **인벤토리**: (텅 빔)
- **관계 상태**:
  - 박세린: 같은 길드 동료 (그녀는 그를 챙김)
  - 회장: 미접촉
  - 강이서(동생): 일상 동거

## 박세린
- **등급**: B (어쌔신)
- **레벨**: 측정값 미공개
- **무기**: 단검 두 자루
- **위치**: 철혈 길드
- **관계 상태**:
  - 강이준: 길드 동료, 누나 같은 존재 ("이준 씨" 호칭)

## 회장 (한도혁)
- **등급**: S
- **위치**: 백화 길드 본부
- **상태**: 강이준 미인지 (1화 이전)

## 강이서
- **나이**: 17세
- **각성**: 미각성
- **위치**: 집 (가족과 거주)
