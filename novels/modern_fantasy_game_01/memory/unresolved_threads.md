- 관리자 권한으로 강제 분리 완료. 유언 남김.

### 강철민의 진실 (ch54 → ch094 회수)

- 한도혁이 감독자 지시로 살해 (분석용 도구로 활용 후 제거).

### 박세진의 진실 (ch47 → ch095 회수)
- v1.7 보유자. 연구 성향→시스템 분석 가능성→감독자가 위협 판단→한도혁에게 제거 지시.

### 시스템의 진짜 목적 (ch45 → ch093 회수)
- 게이트 = 마나 수집 장치. 등급 = 통제 도구. 헌터 = 채굴 도구.
- 감독자 = 외부 존재. 인류 마나를 에너지로 변환→외부 전송.

### 한도혁의 정체 (ch15~ch65 → 3막 회수)

- 3막에서 이준에게 패배.

### 진명 시스템 "통제가 아닌 해방" (ch17 → ch099 회수)
- 박세진 유언. 보유자가 관리자가 되어 통제에서 해방으로 전환.
