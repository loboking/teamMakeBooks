# 세계 상태 — 무등급 헌터

> ch100 완결 시점.

## 시스템 상태
- **진명 시스템**: 정상 작동. 관리자 강이준.
- **감독자**: 분리 완료. 시스템에서 제거.
- **등급 시스템**: 참고치 모드. 통제 도구 아님.
- **마나 장치**: 전국 비활성화. 이식 헌터들은 자연 등급으로 복귀.
- **게이트**: 제어 가능. 관리자 전용 개폐 권한. 필요시에만 개방.
- **보유자 시스템**: 유지 + 관리자 권한 강화. 4명 활성.

## 보유자 연합
- 강이준 (v2.0, 관리자)
- 윤새벽 (v1.3)
- 도서윤 (v1.9)
- 최서연 (v1.1)
- 지원: 김태석 (철혈 길드장), 세린 (이준 동반자)

## 헌터협회
- 마나 장치 비활성화로 대규모 재편.
- 장치 이식 헌터들 자연 등급 추락 (B→C 등).
- 정재훈 A급→C급 하위 추락.
- 협회 중립적 운영 복귀.

## 백화
- 한도혁 제거 후 길드 실질적 해체.
- 산하 헌터들 이탈/자연 등급 추락.
- 백화-협회 협력 협정 자동 무효.

## 철혈 길드
- 소규모 정상 운영.
- 김태석 길드장.
- C급 던전 배정 정상.
- 올바른 길드로 존속.
