# 호칭표 — 무등급 헌터

> **이 표는 결정론적 호칭 검수기의 ground truth.** 본문 속 모든 인물 간 호칭은 여기 정의된 것만 사용.
> 새 인물·관계 추가 시 반드시 이 표 갱신.

## 형식

```
[화자 → 청자]: "호칭" (어조/맥락)
```

---

## 강이준 ↔ 박세린

```
[강이준 → 박세린]: "세린 누나"   (사석/친밀)
[강이준 → 박세린]: "세린 씨"     (공석/길드 회의)
[박세린 → 강이준]: "이준 씨"     (기본/공석/사석 모두)
[박세린 → 강이준]: "강이준"      (긴급/명령 시 — 1화에선 미사용)
```

서술 묘사: "세린은 그를 '이준 씨'라 불렀다." → 대사에서 반드시 "이준 씨" 사용.

---

## 강이준 ↔ 회장 (한도혁)

```
[강이준 → 회장]: "회장님"        (공식 — 거의 모든 상황)
[회장 → 강이준]: "F급 군"        (1막~2막 초반, 경멸·무시)
[회장 → 강이준]: "강이준 씨"     (2막 후반~, 강이준 능력 일부 인지 후)
[회장 → 강이준]: "강이준"        (4막 클라이맥스, 적개심 노출)
```

---

## 강이준 ↔ 김태석 (길드장)

```
[강이준 → 김태석]: "길드장님"     (공식)
[강이준 → 김태석]: "태석 형"     (사석, 1막 일부)
[김태석 → 강이준]: "이준아"      (사석/평소)
[김태석 → 강이준]: "강이준"      (공석 호명)
```

---

## 강이준 ↔ 강이서 (동생)

```
[강이준 → 강이서]: "이서야"      (애정·일상)
[강이준 → 강이서]: "이서"        (긴급)
[강이서 → 강이준]: "오빠"        (모든 상황)
```

---

## 박세린 ↔ 김태석

```
[박세린 → 김태석]: "길드장님"
[김태석 → 박세린]: "세린아"      (사석)
[김태석 → 박세린]: "박세린"      (공석/임무 호명)
```

---

## 강이준 ↔ 윤새벽

```
[강이준 → 윤새벽]: "새벽 씨"     (3막 만남 직후)
[강이준 → 윤새벽]: "윤새벽"      (3막 후반, 친밀)
[윤새벽 → 강이준]: "강이준"      (모든 상황 — 윤새벽 캐릭터의 거리감)
```

---

## 강이준 ↔ 도서윤

```
[강이준 → 도서윤]: "서윤아"      (4막 만남 직후, 동생뻘 인식)
[도서윤 → 강이준]: "이준 오빠"   (4막 친밀)
[도서윤 → 강이준]: "강이준 씨"   (4막 초기/공석)
```

---

## 외부 인물 (조연/엑스트라)

호칭표에 정의되지 않은 인물의 경우, 본문에서 처음 등장 시 호칭을 새로 정의하고 이 표에 추가.
검수기는 정의되지 않은 호칭에 대해 **경고**(통과·반려 아님)를 발행.

---

## 작가/검수자 주의사항

1. 서술 묘사("X는 Y를 'Z'라 불렀다")와 실제 대사 속 호명은 반드시 일치.
2. 같은 화자→청자 관계에서 한 회차 안에 호칭 변경은 사석/공석 전환 시에만 허용.
3. 인물의 등급/관계 변화로 호칭이 바뀔 때는 반드시 변화 트리거 장면을 명시.
