# 세계관 바이블 — 무등급 헌터

> 이 문서는 작품의 헌법. 모든 회차 작가/검수자가 참조. 변경은 반드시 합의 거쳐 새 버전으로.

## 1. 시대 배경

- **2024년 한국.** 5년 전(2019년) 어느 날 갑작스럽게 게이트(차원 균열)가 전 세계에 등장.
- **던전 시대 5년차** — 사회는 적응했지만 균열은 여전히 존재. 사회 구조 자체가 헌터 중심으로 재편됨.
- 게이트는 폐쇄/개방 주기 있음. 닫힌 게이트도 갑자기 다시 열림.
- 헌터 등장 이전의 군대·경찰은 약화. **헌터협회**가 사실상 새 권력.

## 2. 헌터 시스템

### 각성
- 일정 확률로 인간이 게이트의 마나에 노출되어 능력을 얻음.
- 각성 확률 약 0.1%. 한국 인구 5,000만 중 약 5만 명이 헌터.
- 각성 시점은 무작위. 보통 게이트 근처 사고/스트레스 상황에서 발현.

### 등급
- **F → E → D → C → B → A → S**.
- 헌터협회 측정기로 판정. **평생 한 번** 측정. 측정값은 마나 보유량 + 스킬 위력 종합.
- 등급 변화는 수년에 한 번 재측정 가능하나 90%는 평생 같은 등급.
- F급은 사실상 헌터 사회의 최하층. 공식 던전 진입 권한 없음(짐꾼 예외).
- S급은 대한민국 12명. 사회적 신분이 사실상 재벌급.

### 시스템 인터페이스
- 각성자에게만 보이는 게임형 UI. 외부 사람은 못 봄.
- **레벨 / HP / MP / STR / DEX / INT / WIS / FAT** + 인벤토리 + 스킬창 + 퀘스트창.
- **일반 시스템은 던전 내부에서만 활성. 외부에선 비활성** (FAT 등 일부 스탯만 표시).
- **예외 — 진명 시스템**: 일반 시스템과 달리 던전 외부에서도 작동함. 마나 감지, 퀘스트창, 진명 전용 스킬 등은 외부에서도 활성 상태 유지. 이는 진명 시스템이 일반 시스템의 상위 계층이자 별개 시스템이기 때문.
- 스킬: 각성 시 1~3개 보유. 던전 클리어로 추가 획득 가능.

### 진명 시스템 (특수)
- 일반 시스템과 다른 **잠재된 상위 시스템**. 극히 일부에게만 발현.
- 발현 조건: **죽음 직전에 도달했을 때 무작위 부여**.
- 일반 시스템 대비 더 풍부한 정보, 숨겨진 퀘스트, 고유 보상.
- **외부에서 보이지 않음** (다른 헌터가 감지 못함). 측정기로도 측정 불가.
- 한국에 진명 시스템 보유자 추정 5명 미만. 모두 자신의 정체를 숨김.
- **진명 시스템의 정체** (작가만 알 것): 게이트의 진짜 정체와 연결된 안티-시스템. 일반 시스템은 인류를 등급으로 분류·통제하는 도구. 진명 시스템은 그것을 균열시키는 잠금장치 해제 키.

## 3. 던전 / 게이트

### 등급
- F~S. 등급이 같은 헌터 파티가 클리어 가능.
- 보스 처치 시 게이트 닫힘 + 보상(마정석, 장비, 시스템 재화).
- 미클리어 시 **게이트 폭주** → 도시 단위 피해. 헌터협회의 강제 출동 권한 존재.

### 던전 내부 환경
- 등급별 다른 환경: D급은 폐허/광산 모티브, A급은 고대 신전, S급은 별과 우주 모티브.
- 보스: 등급에 따라 강함. 보스 외 잡몹은 헌터 아닌 인간이 근접하면 즉사 수준.
- **던전 심층부**: 일반 던전보다 깊은 구역. 보스 너머에 존재 가능. 거기에 도달하면 등급 너머의 무언가가 있음.

### 마정석 / 보상
- 마정석: 던전에서 채취하는 마나 결정체. 헌터 장비/소비 아이템 제작 재료.
- 시스템 재화: 시스템 안에서만 통용. 인벤토리에서 장비/스킬 구입 가능.
- 경험치: 던전 클리어/퀘스트 완료로 획득. 레벨업 시 스탯 포인트 자동 분배.

## 4. 사회/경제

### 헌터협회
- 정부 산하 공식 기관. 헌터 등록·등급 측정·던전 배정 권한.
- 협회장은 정부 임명. 부패 의혹 다수.

### 길드
- 민간 헌터 조직. 등급별 헌터를 모아 던전 도급/공동 사냥.
- **5대 거대 길드**: 백화 / 백두 / 천검 / 흑야 / 무영. 각각 S급 1~2명 보유.
- **중소 길드**: 수백 개. 5~30명 규모. 강이준 소속 "철혈"은 30명 규모, B급 최강.
- 길드 간 흡수·합병 빈번. 약소 길드는 거대 길드에 흡수되거나 해체.

### 신분 격차
- F급 = 빈민. 짐꾼/잡일. 월수입 200만 원 미만.
- D~C급 = 평민. 회사원 수준 수입.
- B~A급 = 부유층. 대기업 임원급.
- S급 = 재벌급. 사회적 영향력 정치인 수준.

### 짐꾼 직업
- 무등급 또는 F급이 던전에 따라 들어가 짐을 나르는 직업.
- 위험 노출, 보수 낮음. 정식 헌터로 인정받지 못함.
- 강이준의 5년차 직업.

## 5. 작품 핵심 비밀 (작가만 알 것)

> **이 섹션은 검수자/발행팀에게도 노출되지만 본문에 직접 누설 금지. 떡밥/암시로만 흘림.**

### 게이트의 정체
- 게이트는 "외계의 침공"이 아니다.
- 게이트는 **인류를 등급화·통제·실험하기 위한 시스템**의 출입구. 만든 자는 외계의 신적 존재(이름: "감독자").
- 시스템 = 감독자가 인류에게 부여한 통제 도구이자 실험 장치.

### 진명 시스템의 정체
- 감독자가 만든 통제 시스템 안의 **마스터 키**. 감독자도 예측 못한 변종 — 시스템 핵심에 직접 접근 가능한 권한.
- 발현 조건이 "죽음 직전"인 이유: 감독자의 통제 알고리즘 사각지대(임사 의식 상태)에서만 권한 부여 가능.
- 진명 시스템 보유자가 시스템 핵심까지 도달하면 → 감독자의 권한 탈취 → 시스템 통제권 인계 가능.

### 결말 방향 (B형 — 시스템 흡수)
- 강이준이 다른 진명 시스템 보유자(윤새벽, 도서윤)들을 찾아 연합 → 회장(기득권) 처단 → 감독자의 정체 발견 → 감독자 처단 → **시스템 통제권 강이준에게 이전. 그가 새 관리자가 됨.**
- 마지막 장면: 강이준의 등급이 "무등급(Beyond Rank)"으로 표시되며, 그가 시스템 안에서 새 룰을 선포(F급 보호·5대 길드 해체·게이트 폐쇄 권한 등). 시스템은 그대로 작동하지만 이제 그의 손 안에 있다.
- 테마: 약자가 짓밟히던 자에서 시스템 정점에 오른 자로. 시스템은 부수지 않고 **정복한다**.
