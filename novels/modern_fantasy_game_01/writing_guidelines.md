# 작성 가이드라인 — 무등급 헌터

> **모든 회차 작성 전 반드시 숙지.** 이 문서는 1~20화 리뷰에서 발견된 만성적 이슈를 방지하기 위해 작성됨.
> 변경은 반드시 합의 거쳐 새 버전으로.

---

## 1. 4차원 벽 절대 금지 (최우선)

### 규칙
- **본문 서술·내면 독백에서 회차 번호("N화", "N화에서")를 절대 사용하지 않는다.**
- 독자는 캐릭터의 시점에 몰입해야 하며, 캐릭터가 자신이 "N화 주인공"이라는 것을 인지하면 즉시 몰입이 깨진다.

### 금지 예시
- ~~"3화에서 레벨 1이었을 때와 비교하면"~~
- ~~"처음으로 무언가를 죽였던 2화에서의 해방감"~~
- ~~"6화에서 보았던 그 시스템 창"~~

### 대체 방법
- 회차 번호 대신 **시간적/공간적 맥락**으로 대체:
  - "던전에 들어왔을 초기의 레벨 1이었을 때"
  - "처음으로 몬스터를 죽였던 터널 입구에서의 해방감"
  - "며칠 전 보았던 그 시스템 창"

## 2. 시스템 활성 규칙

### 일반 시스템 vs 진명 시스템 (핵심 구분)

| 구분 | 일반 시스템 | 진명 시스템 |
|------|-----------|------------|
| 던전 내부 | 활성 | 활성 |
| 던전 외부 | **비활성** (FAT 등 일부만 표시) | **활성** |
| 타인 감지 | 가능 | 불가 (숨김) |
| 측정기 | 측정 가능 | 측정 불가 (F급으로 위장) |

### 작성 시 주의
- 이준이 던전 **밖에서** 시스템 창/스킬을 사용하는 장면을 쓸 때, 반드시 "진명 시스템"임을 명시하거나 암시할 것.
- 일반 헌터가 던전 밖에서 시스템을 사용하는 장면은 쓰지 않는다.

## 3. 전투 신뢰성 규칙

### 등급 간 격차 원칙
- F급 vs C급: **정면 1:1은 절대 불가.** C급이 정면에서 압도적으로 우위.
- F급이 C급을 이기려면 **반드시 다음 중 최소 2개 이상 조합** 필요:
  - 환경적 우위 (어둠, 좁은 공간, 함정 활용)
  - 기습 (상대가 방심/준비 미흡)
  - 다대1 혼란 (여러 명이 서로 방해)
  - 마나 감지로 인한 선제 행동 (상대의 위치/의도 선독)
  - 진명 시스템 스킬 활용 (생존 본능 등)

### ch20 전투 전례 기준
- 이준이 C급 3명을 이긴 조건: 암실 + 기습 + STR 25(레벨5) + 마나 감지 + 상호 간섭
- 이 조건은 **특수 상황**이며 일반화하지 않는다. 이후 전투에서 동일 조건 재사용 금지.

### 작성 시 체크리스트
- [ ] F급이 C급 이상과 싸우는가? → 환경/기습/스킬 조합이 충분한가?
- [ ] 승리가 너무 쉬운가? → 이준이 부상을 입거나 극한 상태를 거치는가?
- [ ] 관찰자(세린 등)의 반응이 자연스러운가? → 경악/불가능 반응이 포함되는가?

## 4. 마나 감지 일관성

### 고정 수치
- **감지 범위: 200m** (ch005 마나 감지 획득 시 명시됨, 이후 모든 장면에서 동일)
- 범위 내: 마나원 위치, 생명체 위치, 마나 밀도 강도 감지 가능
- 범위 외: 감지 불가. 추적이나 예측은 다른 수단(발자국, 소리 등)으로만 가능

### 작성 시 주의
- 200m 초과 거리를 마나 감지로 감지하는 장면 금지
- 마나 감지가 아닌 일반적 감각(청각, 후각 등)으로 설명할 것

## 5. 반복 패턴 제한

### 가족 플래시백
- 이서/어머니 플래시백: **1화당 최대 1회, 연속 3화 이상 금지**
- 매번 동일한 내용("이서의 얼굴이 스쳤다", "어머니의 약값") 반복 금지
- 변형 필요: 구체적 기억(특정 대화, 특정 장소, 특정 냄새 등)으로 다변화

### 생존 독백
- "살아남아야 한다", "F급이지만", "등급은 뭐든 상관없다" 등: **3화당 최대 2회**
- 대체: 행동으로 생존 의지를 표현 (체인을 쥐는 손, 상처를 무시하고 움직이는 등)

### 아이템/장비 묘사
- 동일한 묘사 반복 금지. 체인, 짐꾼 가방, 마나 포션 등은 최초 1회 상세 묘사 후 축약.
- 이후 언급 시: "체인을 꺼냈다", "가방에서 에너지 바를 꺼냈다" 등 간결하게.

## 6. 타임라인/생리적 일관성

### 시간 추적
- 각 장면의 시간(아침/점심/오후/저녁/밤)을 이전 장면과 모순 없이 유지
- 던전 내부 시간 vs 외부 시간 구분 명확히
- "며칠 후", "다음 날" 등 시간 점프 시 명확한 표식 필수

### 식사/수면/휴식
- 등장인물이 식사/수면 없이 24시간 이상 활동하는 장면은 정당한 이유 없이 금지
- 던전 내부: 에너지 바/포션으로 대체 가능하나, 외부에서는 반드시 식사/수면 묘사 포함

## 7. 캐릭터 연속성 추적

### 상처/부상
- 이전 화에서 입은 부상은 다음 화에서 반드시 언급하거나 치유 과정 거칠 것
- 예: ch003 옆구리 찢김 → ch004~ch005에서 치유/통증 언급
- 부상이 갑자기 사라지는 "전화 증후군" 금지

### 지식/정보
- 이준이 특정 정보를 알게 된 시점 이후에만 해당 정보를 활용 가능
- 예: 백화의 흡수 패턴은 세린이 알려준 후에만 이준이 인지 가능

### 등장/부재
- 이전 화에 등장한 캐릭터가 갑자기 사라지거나 나타나지 않도록 추적
- 길드원 수, 동료 위치 등 일관성 유지

---

## 8. 플롯 이벤트 중복 금지

### 중복 금지 패턴
- 같은 위기 구조를 2화 연속 반복 금지 (예: 연속 "던전 위기 → 간신히 탈출")
- 같은 감정선 반복 금지 (예: "세린의 차가운 눈빛 → 따뜻한 눈빛" 전개 반복)
- 같은 대화 구조 반복 금지 (예: "이준 씨, 괜찮아요?" "괜찮아.")

### 해결책
- 각 화의 핵심 갈등이 이전 화와 다른 유형인지 작성 전 확인
- 갈등 유형: 인간 대 인간, 인간 대 몬스터, 내면 갈등, 사회적 압박, 정보 부족 등

## 9. 주요 캐릭터 역할 수준

### 김태석 (A급 길드장)
- A급은 대한민국 상위 1% 이하의 전투력
- 위기 상황에서 **수동적으로 흔들리는 묘사 최소화**
- 흔들리더라도 A급으로서의 판단력과 결단력은 유지
- F급 짐꾼(이준)보다 상황 파악이 빠르고, 전투 경험이 훨씬 풍부함

### 박세린 (B급 어쌔신)
- B급 전투원으로서의 판단력과 신체 능력은 확실
- 이준을 걱정하더라도 전투 중에는 프로답게 행동
- 정보 수집/분석 능력도 B급에 걸맞게 묘사

## 10. 신규 캐릭터 관리

### 등장 시 필수
- 신규 캐릭터 최초 등장 시: 이름, 등급, 소속, 외모 특징 1개 이상 명시
- 2회 이상 등장하는 캐릭터는 `characters.md`에 추가
- `naming_table.md`에 호칭 규칙 추가 (기존 인물과의 관계가 있는 경우)

### 작성 워크플로우
1. 새 캐릭터 등장 필요 → `characters.md` 확인
2. 미등록 캐릭터 → 작성 후 `characters.md` + `naming_table.md` 업데이트
3. 업데이트는 해당 화 작성과 동시에 진행

## 11. 한국어 문법 규칙

### 조사 일치
- **"김태석"은 모음 종결 명사 → 주격 조사 "가" 불가. 반드시 "이" 사용.**
  - O: 김태석이, 김태석은, 김태석을, 김태석에게
  - X: 김태석가, 김태석를
- 이 외 모든 인물명도 동일 규칙 적용 (모음 종결 → 이, 자음 종결 → 가)

### 중복 조사 방지
- "를를", "을을", "를을" 등 조사 중복 절대 금지
- 예: ~~"코를를"~~ → "코를"

### 띄어쓰기
- 인물명 "이준"은 항상 붙여 쓴다. "이 준"으로 띄어쓰기 금지.
  - 예외: "시스템이 준" (시스템이 주었다)은 정상 표현

## 12. 문체/포맷 규칙

### 호흡 단락 (최우선 스타일 규칙)
- **문장을 묶어서 흐르게 써라.** 관련된 생각·행동·감정은 같은 문장/문단에 연결.
- **1문단 = 여러 문장이 쉼표(,)로 자연스럽게 이어지는 흐름.** 자꾸 엔터 치지 마.
- "한숨에 하나" = 하나의 호흡으로 읽힐 만큼 문맥을 끊기지 말고 이어가라.
- 대화 전후 서술도 자연스럽게 앞뒤 문장과 연결. 불필요한 엔터 금지.
- 1화 목표: 5000~5500자 (한국어 기준)

### 시스템 알림 표기
- 대괄호 사용: `[퀘스트 갱신]`, `[HP: 15/250]`
- 시스템 메시지는 본문과 구분되도록 대괄호로 감쌈

### 장면 전환
- `***` 로 장면 전환 표시
- 장면 전환 시 시간/공간 변화를 첫 문장에 명시

## 13. 외래어 한글화 규칙

### 장르 표준어 (유지)
- 마나, 길드, 던전, 헌터, 게이트, 보스, 퀘스트, 레벨 — 한글화 금지

### 한글화 필수
- 어쌔신 → 암살자 / 탱커 → 방패수 / 딜러 → 공격수 / 힐러 → 치유사
- 패시브 → 상시 / 쿨타임 → 재사용 시간 / 파티 → 일행
- 스탯 → 능력치 / 스킬 → 기술 / 아이템 → 물건

### 시스템 창 한글 표기
- HP → 체력 / MP → 마력 / STR → 근력 / DEX → 민첩 / INT → 지능 / WIS → 지혜 / FAT → 지구력
- 예: `[근력: 25] [민첩: 30]` / `[체력: 15/250]`

## 14. 계절/시간/월 일관성
- 작품 내 시간대는 확정 후 모든 화에서 동일. 현재: **11월**.
- 계절 묘사(바람, 온도, 식물)가 시간대와 모순되지 않아야 함.
- 작성일(발행일)과 작품 내 시간을 혼동하는 메타 오류 금지.

## 15. 동명이인/인물 관리 강화
- 이미 등장한 인물과 동일한 이름 사용 금지.
- 길드원 인원 변동은 반드시 `timeline.md`에 누적 기록. "N명 중 X명 매수" 등 수치 명시 시 이전 화 인원과 정합성 확인.
- 인물 이탈/사망 시 반드시 본문에서 명시.

## 16. 클리프행어 회수 규칙
- N화 끝에 던진 클리프행어는 N+1화 첫 장면에서 반드시 직접 다뤄야 함.
- "다음 날, 상황은 마무리되었다" 식 한 줄 요약 회수 금지.

## 17. 한자/외국어 혼입 금지
- 본문에 한자, 일본어, 영어(장르 표준어 제외) 직접 노출 금지.
- 검수 전 반드시 grep으로 외래문자 노출 점검.
