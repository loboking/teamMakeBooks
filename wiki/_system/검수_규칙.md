# 회차 검수 규칙

## 검수 순서

```
writer_draft → naming → direction → character → quality → repetition → polish → publisher
```

## 인물 호명 한도 (작품 meta.json의 main_characters에서 동적 로드)

작품별 한도 예시:
- 무등급 헌터: 강이준 풀=7/짧=15, 박세린 풀=5/짧=15
- 이계 무역가: 차하린 풀=5/짧=35, 마린 풀=25, 한도영 풀=10, 도원 영감 풀=10, 좌선장 풀=10

## 동작동사·연속주어 한도 (전 작품 공통)

- 동작동사 (`바라보았다·확인했다·끄덕였다 등 12개`) — 각 ≤ 4회
- 연속주어 (같은 주어로 시작 N문장) — ≤ 8문장
- 등급직업 (F급/D급/.../S급) — 각 ≤ 3회 (헌터물에서만 의미)

## 5회 소진 시 정책

- repetition 검수 5회 후에도 한도 초과 시 **경고 마킹 후 발행** (halt X)
- review_history에 "경고: {사유}" 기록
- 사용자가 발행물 보고 수동으로 polish 추가 가능

## 위키 참조 (도입 시)

- character 검수자: `wiki/{wid}/characters/{이름}.md` frontmatter + 누적 상태와 본문 비교
- direction 검수자: `wiki/{wid}/threads/*.md` open 떡밥 회수 여부 확인
- quality 검수자: `wiki/{wid}/timeline.md` 직전 사건과 연결성 확인
